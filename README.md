# Scripts for the paper "Topology-independent quantum advantage in communication networks" arXiv:2610.04734.

# In "3 party_extremal_points_generation.py" file contain python script for generating the extremal points of all the topology independent scenarios.

# In "Alice to Bob to Charlie seesaw.m" contain the seesaw code for the three party quantum violation for the facets discussed in the paper. This code contains sequential communication.

# In "spatially separated sender's and receiver_seesaw.m" file contain the seesaw code to check three party quantum violation for the spatially separated senders and a single receiver.

# In "fourparty A to B to R.py" scripts for generating extremal points of Alice to Bob to receiver for the four party case.
